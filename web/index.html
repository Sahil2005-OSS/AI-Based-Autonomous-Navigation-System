Safety Contract & Invariant Guarantees

Core algorithmic principles eliminating common robotics failure modes.

Swept-Footprint Geometry

Evaluates continuous movement segment S=[P0, P1] carrying circular envelope R against all obstacle cells using exact slab intersections and extreme-point distance minimization. Tangential contact counts as collision.

Temporary World Isolation

Dynamic obstacle detour replanning clones the base occupancy grid and rasterizes transient obstacle bodies onto isolated temporary layers. The permanent base map remains 100% immutable.

Fail-Safe Halting Contract

If passages are fully blocked or the replan budget is exhausted while in conflict, the controller commands zero velocities (v=0, omega=0) and transitions to BLOCKED with zero collisions.
